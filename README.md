# 猫夏云芯（DaS YunXin）

面向嵌入式开发者的抖音小程序：**芯片资料速查 + 嵌入式工具箱**。全部功能离线可用，无需登录。

## 功能

### 芯片速查
- **搜索**：内置 109 款常用芯片（41 厂商 / 12 品类），支持型号模糊、厂商、品类、简介匹配；自动补全、搜索历史、热门推荐
- **详情页**：核心参数表（内核/主频/Flash/RAM/封装/电压…）、官方数据手册直链（复制后浏览器打开）、替代料下钻（如 STM32F103 → GD32/CH32）、收藏
- **分类浏览**：按厂商、按品类双维度

### 嵌入式工具箱（12 件套）
| 工具 | 说明 |
|---|---|
| 色环电阻计算 | 4/5/6 环逐环选色，实时阻值 + 精度 + 读数式 |
| 进制转换 | HEX/DEC/BIN/OCT 互转，8/16/32 位宽，ASCII 对照 |
| 分压计算 | Vin/R1/R2/Vout 任填三项求第四项，附分压电流 |
| 定时器计算 | STM32 PSC/ARR ↔ 周期正反向，附三组推荐组合 |
| 协议速查 | UART/SPI/I2C/CAN 引脚定义、参数与实战要点 |
| 单位换算 | dBm ↔ mW、频率 ↔ 周期、波特率传输时间 |
| LED 限流电阻 | E24 标准阻值推荐 + 实际电流 + 封装功率建议 |
| 欧姆定律 | V/I/R/P 任填两项求其余两项 |
| RC 时间常数 | τ、1τ~5τ 充放电时间表、滤波截止频率 fc |
| ADC 换算 | 读数 ↔ 电压双向互算，8/10/12/16 位可配 |
| 555 定时器 | 无稳态频率/占空比 + 单稳态脉宽双模式 |
| 电池续航 | 容量/电流/效率 → 天-小时续航 + Wh 能量 |

## 开发

1. 下载 [抖音开发者工具](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/develop/developer-instrument/download/developer-instrument-update-log)
2. 导入本仓库，填入自己的 appid（`project.config.json`）
3. 真机预览请参考抖音官方文档配置隐私协议（剪贴板）等权限

### 真机适配要点（踩坑记录）
- **数据手册**：境外厂商域名无法配置白名单（要求 ICP 备案），采用「复制官方 PDF 直链 + 引导浏览器打开」方案
- **剪贴板**：需在抖音开放平台后台「用户隐私保护协议」中声明「剪贴板」信息类型，否则 `tt.setClipboardData` 返回 10202 被平台拦截
- **ttml 模板**：表达式仅支持基础算术 / `==` / 逻辑 / 三元 / `obj.key` 点运算；不要在 `tt:for` 循环内用变量索引（`values[item.key]`）或在 class 中做严格比较（`===`），会导致真机页面空白/渲染异常
- **输入框**：采用半受控模式（onInput 不回写 value），避免 setData 重渲染干扰真机粘贴
